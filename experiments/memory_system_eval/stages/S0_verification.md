## Lessons carried into this project

1. **J-BRAIN cannot be the memory reader.**
   - Recall from context reaches chance by about 256 tokens (C01).
   - The model does not copy (C05; LAMBADA C04).
   - It cannot bind two facts (C06).
   - Even with WAEM supplying the right slot, J-BRAIN's own answering was 0% (C10, C12).
   - So payloads must be **delivered verbatim** by the memory system, not regenerated by the LM.
2. **Present but not read out.** A probe finds the key where the LM's output does not (C01b). So frozen J-BRAIN states can serve as *features* for small heads, but only locally: by 64 tokens the probe has fallen to 35%.
3. **Precision matters.**
   - bf16 kills 33 of 144 heads (C04b), so feature extraction here runs in fp32.
4. **Architectural add-ons were unreliable.**
   - The C1/C3 MQAR results (C07, C08) show that small recurrence changes did not robustly fix retrieval.
   - In any case, they are excluded by this project's constraints.
5. **WAEM's storage was exact, its addressing was not** (C09).
   - Exact-given-accepted was 0.97–1.00.
   - Exact over answerable questions was 0.05–0.49 at about 1% FAR.
   - Stage 1 shows the benchmark itself was lexically trivial. This is the main benchmark inconsistency inherited from earlier work.
